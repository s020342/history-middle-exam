# 教师原创题目填写说明

> 面向初中历史教师的简明指引。您只需要一个文本编辑器（记事本/VSCode 均可），照着模板填写即可。

## 一、三步上手

1. **复制模板**：将 `template.yaml` 复制一份，重命名为 `teacher-您的姓名.yaml`（如 `teacher-张老师.yaml`），一人一个文件。
2. **填写题目**：参照文件内两条示例题的格式，替换成您的题目。可使用 `sample.yaml`（10 道完整成题）作为填写示范。
3. **交回审核**：将填好的文件交回教研负责人，由负责人统一校验、去重、导入题库。

## 二、字段说明

### 必填字段

| 字段 | 说明 | 示例 |
|------|------|------|
| externalId | 题目编号，按 `T-001`、`T-002` 依次递增 | `T-001` |
| type | 题型：选择题 `SINGLE_CHOICE`，判断题 `TRUE_FALSE` | `SINGLE_CHOICE` |
| stem | 题干，选择题以问句结尾，判断题为陈述句 | `秦始皇统一六国的年份是？` |
| options | 选择题填 2~4 个选项（key 依次 A/B/C/D）；判断题保持 `null` | `{key: A, content: 公元前221年}` |
| answer | 选择题为选项 key 之一；判断题 `T`（对）/ `F`（错） | `A` / `T` |
| knowledgeIds | 考点编码，从下方编码表选择，至少 1 个，可多选 | `[K-CHN-ANC-QIN-HAN]` |
| difficulty | 难度：`1` 易 / `2` 中 / `3` 难 | `2` |
| author | 您的姓名，用于署名与来源追溯 | `张老师` |

### 选填字段

| 字段 | 说明 | 建议 |
|------|------|------|
| analysis | 解析。**强烈建议填写**，人工审核主要看解析的史实依据 | 写明关键年份、人物、因果 |
| tags | 标签，如 `[高频, 秦汉史]` | 便于后续组卷 |

### 无需填写（系统自动补默认值）

| 字段 | 默认值 |
|------|--------|
| sourceType | `ORIGINAL`（原创） |
| license | `CC-BY-SA-4.0` |
| subject | `HISTORY` |
| primaryKnowledgeId | 自动取 knowledgeIds 的第一个 |
| sourceDesc | 可填"教师原创"，也可不填 |

## 四、命题要求

1. **原创性**：必须是您本人原创命题，不得直接改编教辅、真题汇总等受版权保护的材料。
2. **史实准确**：关键年份、人物、事件表述须与统编教材口径一致。
3. **解析完整**：每题建议写明史实依据，帮助学生理解错因。
4. **合规表述**：涉及领土、民族、近现代史的表述，遵循教育部审定统编教材口径。

## 五、常见校验错误对照

提交前可对照下表自查，以下错误会被工具自动拦截并退回修改：

| 错误现象 | 原因 |
|----------|------|
| 答案不在选项中 | answer 填了 E 或选项里没有该 key |
| 判断题被拒 | 填了 options，或答案写成了"对/错"（应为 T/F） |
| 考点编码未知 | knowledgeIds 不在编码表内，或拼写错误 |
| 选项 key 重复 | 两个选项都用了同一个 key |
| 文件解析失败 | 冒号后少了空格、缩进不对（用空格，不要用 Tab） |
