## 1. 后台概述

### 1.1 访问入口
- 地址：`https://admin.example.com`
- 浏览器：Chrome / Edge / Safari 最新两个版本。
- 推荐分辨率：1920×1080，最低 1366×768。

### 1.2 角色与权限（RBAC）
| 角色 | 典型权限 | 适用人员 |
|------|----------|----------|
| 超级管理员 ADMIN | 全部 | 平台负责人 |
| 教研员 TEACHER | 题库管理、知识点、小测配置、学习看板 | 教师 |
| 运营 OPERATOR | 订阅价格、公告、配置 | 运营 |
| 只读审计 VIEWER | 看板查看、日志查看 | 审计 |

> 超级管理员可在「系统 → 角色与权限」分配角色与权限点。

### 1.3 登录与安全
- 账号密码登录，密码 BCrypt 加盐存储。
- 连续 5 次密码错误锁定 30 分钟。
- 强制密码 90 天更换，新密码不可与最近 3 次重复。
- 所有写操作（题库变更、订阅配置、价格调整）记录操作日志。

## 3. 题库管理

### 3.1 题目列表
- **筛选**：题型、考点、难度、来源类型（真题改编/模拟/原创/开源搬运）、状态（上架/下架/审核中）、关键词。
- **字段**：ID、题型、题干预览、难度、来源、正确率、状态、更新时间。
- **批量操作**：上架、下架、删除（软删）、导出 JSON。

### 3.2 新增题目
1. 点击「新增题目」。
2. 选择题型：选择题 / 判断题。
3. 填写题干（支持富文本与图片上传至 OSS）。
4. 选择题：维护选项 A/B/C/D，标记正确答案。
5. 判断题：选择正确（T/F）。
6. 填写解析（必填）。
7. 关联考点（至少 1 个，标记主考点）。
8. 选择难度（易/中/难）、来源类型、来源年份（真题改编时填）、来源描述。
9. 关联变式题（可选）：从题库搜索 1~2 道关联为「同类」或「变式」。
10. 版权追溯字段（必填）：
    - license：CC-BY-SA-4.0 / MIT / ORIGINAL 等。
    - author：原作者或投稿教师。
    - sourceUrl：来源链接（原创可空）。
11. 保存为「审核中」，审核通过后「上架」。

【截图占位：ADM-05 新增题目表单页】

### 3.3 编辑与审核
- 编辑：字段同新增，保留变更历史（题目版本表）。
- 审核：教研员审核「审核中」题目，通过则上架，驳回需填写原因。
- 审核 Checklist：
  - [ ] 题干表述清晰、无歧义。
  - [ ] 答案与解析正确，史实无误。
  - [ ] 考点关联准确。
  - [ ] 版权字段完整、license 合规。
  - [ ] 政治与敏感表述合规。

### 3.4 批量导入
- **入口**：题库管理「批量导入」。
- **格式**：JSON（Schema 见 docs/05-数据抓取方案文档.md 第 3 节）。
- **流程**：
  1. 上传 JSON 文件。
  2. 系统校验 Schema、license 合规、external_id 去重。
  3. 返回 `{ inserted, skipped, conflicted }` 统计。
  4. 冲突项可下载明细 CSV 修正后重导。
- **版权校验**：导入时自动拒绝 `sourceType=PAST_EXAM_RAW`（真题原文）与 license 缺失的题目。
- **导入日志**：每次导入生成 `question_import_log`，可按批次回滚（软删该批次）。

【截图占位：ADM-06 批量导入页 + 导入结果统计】

### 3.5 变式题关联
- 题目详情页「变式题」标签。
- 搜索题目 → 关联为「同类 / 变式」。
- 学生答错原题时自动推送变式题 1~2 道。

## 6. 小测配置

### 6.1 小测排期
- **入口**：「小测 → 排期管理」。
- **字段**：标题、开考时间、截止时间、题量、时长（分钟）、组卷规则（JSON）、状态（草稿/启用/停用）。
- **组卷规则示例**：
  ```json
  {
    "knowledgeDistribution": [{"knowledgeId":"K1","count":5},{"knowledgeId":"K2","count":5}],
    "difficultyRatio": {"easy":3,"medium":12,"hard":5},
    "typeRatio": {"single":15,"trueFalse":5}
  }
  ```
- **调度**：开考时间到达时由 XXL-Job 触发，截止时自动批改未交卷学生。

### 6.2 小测结果
- 查看每场小测参与人数、平均分、分数分布。
- 单学生结果：分数、用时、错题、错因。

## 7. 订阅与运营

### 7.1 订阅方案
- **入口**：「运营 → 订阅方案」。
- **字段**：方案编码（MONTHLY）、名称、价格（分）、时长（天）、免费体验每日题量、状态。
- **变更**：价格调整需二次确认，记录操作日志，次日 0 点生效。
- **历史**：保留价格变更历史，便于对账。

### 7.2 订单与对账
- **入口**：「运营 → 订单」。
- **字段**：订单号、学生、方案、金额、状态、微信支付单号、支付时间。
- **对账**：每日 03:00 拉取微信支付账单与本地订单比对，异常告警。
- **退款**：超级管理员权限，填写退款原因，调用微信退款接口。

### 7.3 公告与活动
- **入口**：「运营 → 公告」。
- 公告在小程序首页 banner 展示，支持富文本与跳转链接。
- 草稿/已发布状态，可下线。

### 7.4 配置项（app_config）
- 免费体验额度、复习提醒时间、小测默认时长等。
- 修改即时生效，敏感配置（如价格）需二次确认。

## 8. 系统管理

### 8.1 用户与角色
- 管理员账号 CRUD、分配角色、重置密码、停用。
- 角色 CRUD、角色-权限点分配。
- 权限点列表（如 `question:create`、`student:view`）。

### 8.1.1 管理员账号开通流程

#### 触发场景
- 新管理员入职。
- 外部教研员/教师合作接入。
- 临时账号（如审计人员短期查看）。

#### 开通步骤
1. **申请发起**：所在部门负责人提交《后台账号申请表》，包含：姓名、岗位、申请角色（ADMIN/TEACHER/OPERATOR/VIEWER）、申请事由、有效期、审批人。
2. **审批**：超级管理员或授权审批人审核申请表，确认角色与权限范围合理。
3. **开通账号**：超级管理员在「系统 → 用户管理」执行：
   1. 新建管理员：填写 username（建议拼音首字母+工号，如 zhangsan001）、姓名、初始密码（系统生成 12 位强密码，单独渠道送达）。
   2. 分配角色：勾选对应角色，权限点随角色自动继承；如需精细控制，可手动增减权限点。
   3. 标注有效期：临时账号填写到期日，到期自动停用（定时 Job 巡检）。
   4. 状态：启用。
4. **凭证送达**：初始密码通过企业微信/钉钉点对点发送，禁止邮件群发；首次登录强制改密。
5. **登录验证**：新管理员登录后台 → 修改密码 → 确认可见菜单与权限。
6. **操作日志**：开通操作记入操作日志（操作人、被开通人、角色、时间、IP）。

#### 开通后培训
- 新管理员首次开通后，由超级管理员或同级管理员讲解：后台使用规范、题库版权红线、操作日志与审计要求。
- 培训记录归档。

#### 角色与权限变更
- 岗位变动：超级管理员调整角色，操作日志记录前后角色。
- 临时权限提升：填写《临时权限申请》明确时长，到期自动回收。

### 8.1.2 管理员账号注销流程

#### 触发场景
- 离职 / 合作结束。
- 长期未登录（90 天无登录）。
- 违规操作被冻结。
- 临时账号到期。

#### 注销步骤
1. **注销申请**：所在部门发起注销申请，或系统自动标记候选注销账号（90 天未登录）。
2. **审批**：超级管理员确认注销，核对未结事项。
3. **未结事项核对**：
   - 题库审核中任务：转交他人或退回提交人。
   - 小测排期中归属该管理员的：改派他人或转交超级管理员。
   - 订单退款流程中：必须完结或移交。
   - 操作日志：不可移交，永久保留追溯。
4. **执行注销**：超级管理员在「系统 → 用户管理」操作：
   1. 状态改为「停用」（软停用，账号不可登录，但记录保留）。
   2. 解除当前会话：强制下线该账号所有在线 token（清理 `admin:token:*`）。
   3. 收回所有权限点与角色关联（保留历史记录，仅做失效处理）。
   4. 标注注销时间、注销人、注销原因。
5. **不可物理删除**：管理员账号记录永久保留，便于审计追溯；列表默认隐藏已注销账号，可通过筛选查看。
6. **操作日志**：注销操作记入操作日志，关联该账号历史操作全链路可查。

#### 特殊情况
- **紧急冻结**：发现违规操作或账号泄露，超级管理员可一键冻结（status=停用 + 强制下线），事后补审批。
- **注销后恢复**：原则上不恢复；确需恢复的，新建账号而非启用旧账号，避免权限混淆。
- **数据归属**：该管理员产生的题库、配置、订单等业务数据不随账号注销变更归属，仍可继续使用。

#### 注销后核对（48 小时内）
- [ ] 账号已停用，无法登录。
- [ ] 在线会话已清理。
- [ ] 未结任务已转交。
- [ ] 操作日志完整可查。
- [ ] 通知原所在部门注销完成。

### 8.1.3 账号生命周期管理 Job
- **每日 02:00 巡检 Job**：
  - 扫描 90 天未登录且非超管账号 → 标记为「待注销」并通知超级管理员。
  - 扫描临时账号到期 → 自动停用并通知申请人与审批人。
- **每周一 08:00 报表**：本周待注销账号清单邮件至超级管理员确认。
- **审计**：每季度由 VIEWER 角色审计账号清单，确认无僵尸账号。

### 8.2 操作日志
- **入口**：「系统 → 操作日志」。
- 记录：操作人、时间、模块、动作、对象 ID、前后值摘要、IP。
- 保留 6 个月，支持按操作人/模块/时间筛选。

### 8.3 登录日志
- 记录管理员登录成功/失败、IP、UA。
- 异常登录（异地、夜间）告警。

## 9. 运维操作

### 9.1 缓存管理
- **入口**：「系统 → 缓存」。
- 支持按 Key 前缀清理：`student:mastery:*`、`quiz:session:*` 等。
- 危险操作需二次确认 + 操作日志。

### 9.2 任务调度
- 查看 XXL-Job 任务列表（复习队列生成、小测触发、对账、备份）。
- 支持手动触发（如补跑复习队列）。
- 失败任务告警。

### 9.3 题库回滚
- **入口**：「题库 → 导入日志」。
- 按批次软删（status=下架）该批次题目，不影响已产生的训练记录。
- 不可物理删除（保留追溯）。

### 9.4 短信平台配置
- 阿里云短信：AccessKey / Secret / 短信签名 / 模板 ID（家长绑定验证码）。
- 配置存环境变量，不入库。
- 每日发送量监控，超额告警。

## 10. 常见运维场景

### 10.1 题目报错处理
1. 学生在小程序「报错」提交，后台「题库 → 报错列表」查看。
2. 教研员核实：题干/答案/解析错误 → 编辑修正 → 重新审核上架。
3. 已答错的学生补偿：手动赠送 1 次免广告权益或推送通知。

### 10.2 支付异常处理
- 学生反馈已支付未开通：
  1. 「订单」搜索学生订单，确认状态。
  2. 若本地未确认但微信已支付，拉取微信支付单号核对。
  3. 手动确认订单，开通权益，记录处理人。
  4. 通知学生。

### 10.3 小测未触发
- 检查 XXL-Job 调度状态与日志。
- 手动触发该场小测开考任务。
- 通知学生补做窗口。

### 10.4 掌握度异常
- 学生反馈掌握度未更新：
  1. 清理该学生 `student:mastery:{sid}` 缓存。
  2. 触发掌握度重算 Job。
  3. 仍异常则人工排查 train_record。

### 10.5 题库版权投诉
- 收到第三方版权投诉：
  1. 立即下架涉事题目（status=下架）。
  2. 调取 license/author/source_url 证据链。
  3. 48 小时内回应投诉方。
  4. 若证据不足，永久删除并复盘抓取流程。

## 11. 常见问题（FAQ）

| Q | A |
|---|---|
| 如何批量上架题目？ | 题库列表勾选多题 → 批量上架。 |
| 导入 JSON 报错怎么看？ | 下载冲突明细 CSV，按 external_id 排查。 |
| 能否修改已上线小测规则？ | 已开考不可改，未开考可改但需通知学生。 |
| 价格调整后老订阅会变吗？ | 不会，已生效订阅按原价格至到期。 |
| 管理员误删题目怎么办？ | 软删可恢复；导入批次可在导入日志回滚。 |
| 后台无法登录？ | 检查账号状态、密码错误次数；5 次错误锁定 30 分钟。 |
