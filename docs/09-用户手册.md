## 1. 产品简介

「史小练」是一款专为中考历史备考设计的微信小程序。它通过「题库训练 + 错因归因 + 间隔复习」的科学方法，帮你：
- 在短时间内掌握历史全部主考点；
- 知道为什么错，避免重复踩坑；
- 用最少的时间巩固薄弱知识；
- 通过每周小测检验真实水平。

## 2. 快速开始

### 2.1 进入小程序
1. 打开微信，下拉聊天列表进入「小程序」入口。
2. 顶部搜索「史小练」或扫描下方小程序码。
3. 首次进入会请求微信授权登录，点击「允许」即可。

> 你无需注册账号，使用微信即可登录，学习数据自动保存。

### 2.2 三步开始训练
1. 打开首页 → 点击「自由训练」。
2. 选择考点（如"秦汉"）或「随机出题」，设置题量后开始。
3. 逐题作答，提交后立即看到正确答案、解析和掌握度变化。

## 3. 功能详解

### 3.1 自由训练
- **入口**：首页「自由训练」。
- **组卷方式**：
  - 按考点：选择一个或多个考点。
  - 按题型：仅选择题 / 仅判断题 / 混合。
  - 随机：从全部题库中随机抽取。
- **作答**：点击选项后可修改，确认后提交；提交后不可改。
- **即时反馈**：正确显示绿色、错误显示红色，并展示解析。

【截图占位：IMG-03 选择题答题 / IMG-04 判断题答题 / IMG-05 正确反馈 / IMG-06 错误反馈+解析】

### 3.2 错题本
- **入口**：底部 Tab「错题」。
- **作用**：自动收集所有错题，按考点归类。
- **操作**：
  - 重做：直接进入错题训练。
  - 移除：连续答对 2 次后可手动移除。
  - 标错因：可选「知识点不会 / 概念混淆 / 审题陷阱」帮助归因。

【截图占位：IMG-07 错题本列表】

### 3.3 错误归因
答错后小程序会弹出错因选择层。请如实选择，系统将：
- 「知识点不会」→ 推送对应知识点卡片。
- 「概念混淆」→ 推送易混对比卡片。
- 「审题陷阱」→ 标记陷阱类型，后续遇到同类陷阱提醒。
- 第二次答错同一类题 → 自动推送 1~2 道变式题验证。

【截图占位：IMG-08 错因选择弹层 / IMG-09 变式题验证推送】

### 3.4 知识点卡片
- **入口**：训练解析页「查看知识点」、首页「知识点」Tab。
- **内容**：核心结论、时间轴、易错提示、关联题。
- **操作**：收藏、跳转关联题训练。

【截图占位：IMG-10 知识点卡片详情页】

### 3.5 三档掌握度
每道题与每个考点都有掌握度状态：
| 颜色 | 含义 | 你的目标 |
|------|------|----------|
| 🔴 红色 | 未掌握 | 1 天内复习 |
| 🟡 黄色 | 部分掌握 | 3 天内巩固 |
| 🟢 绿色 | 已掌握 | 7 天内复测 |

> 系统会自动跟踪你连续答对的次数决定升降档，无需手动维护。

【截图占位：IMG-11 掌握度分布与升降档提示】

### 3.6 间隔复习
- **入口**：首页「今日复习」。
- **机制**：每天系统自动生成到期复习题，做完即更新掌握度。
- **提醒**：可在「我的 → 通知设置」开启复习提醒（订阅消息）。

【截图占位：IMG-12 今日复习队列页】

### 3.7 每周限时小测
- **时间**：每周日 20:00 自动开放，可补做（无排名）。
- **规则**：20 题 / 20 分钟，到时自动交卷。
- **入口**：首页 banner 或「小测」入口。
- **结果**：交卷后立即看到分数、错题、错因分布。

【截图占位：IMG-13 小测入口 banner / IMG-14 小测答题页（倒计时）/ IMG-15 小测结果页】

### 3.8 训练报告
- **入口**：「我的 → 训练报告」或报告推送。
- **内容**：
  - 本周训练量、正确率。
  - 掌握度变化（升/降题数）。
  - 薄弱考点 Top3。
  - 错因分布饼图。
  - 复习完成率。

【截图占位：IMG-16 周报总览（正确率折线）/ IMG-17 错因分布饼图】

### 3.9 订阅与支付
- **免费体验**：每日限定题量 + 1 个考点试用。
- **月订阅**：解锁全题库、间隔复习、限时小测、训练报告。
- **支付**：微信支付，30 天有效，到期前 3 天提醒续费。
- **入口**：「我的 → 订阅」或被免费额度限制时弹窗引导。

## 5. 家长端使用说明

> 「史小练」未单独提供家长端 App，家长通过同一小程序以"家长身份"使用。家长可绑定孩子账号，查看学习报告并代付订阅，但不代替孩子刷题（避免数据污染）。

### 5.1 绑定孩子账号
1. 家长用自己微信进入「史小练」小程序。
2. 首页点击「我是家长」入口（首次进入会引导）。
3. 输入孩子在小程序中登记的手机号，并完成短信验证码校验：
   - 孩子需在「我的 → 手机号绑定」中先登记手机号（一次登记，长期有效）。
   - 家长输入该手机号后，系统向该手机号发送 6 位短信验证码，10 分钟内有效。
4. 验证通过后，家长账号与孩子账号建立绑定关系。
5. 一个家长可绑定多个孩子（如双胞胎），一个孩子最多绑定 2 位家长。
6. 若同一手机号对应多名孩子（极少数情况），验证通过后由家长选择具体孩子账号完成绑定。

【截图占位：IMG-21 家长入口 + 手机号输入页 / IMG-22 短信验证码页 + 绑定成功页】

### 5.1.1 手机号绑定注意事项
- 手机号是绑定凭证，请确保孩子手机号登记准确且为常用号码。
- 孩子修改手机号后，已绑定家长关系保持不变；新家长绑定需用最新手机号。
- 若孩子未登记手机号，家长可在家长端引导孩子先完成手机号登记。
- 短信验证码每日每手机号发送上限 5 次，防滥用。
- 绑定后家长可在「家长中心 → 孩子管理」查看与解绑，孩子可在「我的 → 家长绑定」中移除家长。

### 5.1.2 短信验证码安全
- 验证码仅用于绑定校验，不用于登录。
- 连续 3 次输入错误验证码，该手机号 30 分钟内禁止再次发起绑定。
- 验证码不通过电话/短信外发以外的方式索取，谨防诈骗。

### 5.2 查看孩子学习报告
- **入口**：家长身份首页「孩子报告」。
- **内容**：
  - 本周训练量、正确率、连续学习天数。
  - 三档掌握度分布（红/黄/绿比例）。
  - 薄弱考点 Top3。
  - 错因分布（知识点不会 / 概念混淆 / 审题陷阱 占比）。
  - 复习完成率与今日是否完成。
- **说明**：家长仅可查看汇总与趋势，不可查看具体题目作答记录（保护孩子隐私）。

【截图占位：IMG-23 家长报告总览页 + 薄弱考点详情】

### 5.3 代付订阅
1. 家长身份首页点击「为孩子订阅」。
2. 选择订阅方案（月订阅）。
3. 微信支付完成，权益自动开通到孩子账号。
4. 孩子端会收到订阅开通通知。
- **说明**：家长代付与孩子自付权益一致，订阅记录归属于孩子账号。

【截图占位：IMG-24 代付下单页 + 支付成功页】

### 5.4 续费提醒
- 订阅到期前 3 天，家长与孩子都会收到订阅消息提醒。
- 家长可在「家长中心 → 订阅管理」开启/关闭自动续费提醒。

### 5.5 解绑
- 家长：「家长中心 → 孩子管理 → 解绑」，解绑后不再查看该孩子报告。
- 孩子：「我的 → 家长绑定 → 移除家长」。
- 解绑不影响已有订阅权益。

### 5.6 家长常见问题
| Q | A |
|---|---|
| 收不到验证码怎么办？ | 检查手机号是否为孩子登记号码、信号是否正常；60 秒后可重发；当日上限 5 次。 |
| 绑错孩子怎么办？ | 解绑后重新绑定正确账号。 |
| 孩子换手机号了还能绑定吗？ | 已绑定关系不受影响；新家长需用孩子最新手机号绑定。 |
| 两位家长都能代付吗？ | 可以，权益叠加顺延。 |
| 看不到孩子具体错题？ | 设计如此，仅展示汇总分析，保护孩子隐私。 |

## 6. 常见问题（FAQ）

### Q1 数据会丢失吗？
不会。所有学习数据保存在云端，更换手机或重装微信仍可恢复。

### Q2 没网络能用吗？
不能答题，但可查看已缓存的错题与知识点卡片。

### Q3 免费额度是按日还是按总？
按日。每日 0 点重置。

### Q4 订阅到期后错题会没吗？
不会。错题本永久保留，但间隔复习与小测需订阅才能继续使用。

### Q5 支付后未开通怎么办？
请勿重复支付。在「我的 → 订阅」点「刷新权益」，或通过「帮助与反馈」联系客服。

### Q6 小测没赶上时间怎么办？
小测结束后可补做，但无排名，仍会计入训练报告。

### Q7 答案与解析有错误怎么办？
在题目解析页点「报错」，描述问题，后台审核后修正并补偿错题。

### Q8 如何取消订阅提醒？
「我的 → 通知设置」关闭对应开关，或微信「服务通知」中取消订阅。

## 7. 学习建议
1. **每日 20 题**：保持手感，避免考前突击。
2. **重视错因**：选错因不是负担，是让你看清薄弱点。
3. **必看卡片**：知识点卡片比单题更值钱。
4. **跟上复习**：今日复习当天做完，避免堆积。
5. **参加小测**：每周一次检验，比刷题更能反映水平。

## 8. 隐私与安全
- 仅收集必要信息：微信昵称、头像、年级。
- 不收集身份证号、家庭住址等敏感信息。
- 学习数据仅用于个人学习分析与产品优化，不会未经同意共享给第三方。
- 详细条款见小程序内「隐私协议」。

## 9. 帮助与反馈
- 小程序内：「我的 → 帮助与反馈」。
- 反馈类型：题目报错、功能建议、支付问题、账号问题。
- 客服响应时间：工作日 9:00-18:00，24 小时内回复。
