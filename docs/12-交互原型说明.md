| 项 | 内容 |

| 文档版本 | v1.0 |

---

## 1. 交互设计原则

1. **即时反馈**：用户每次操作 200ms 内必有视觉响应。
2. **状态可见**：进度、倒计时、掌握度变化全程可见。
3. **可逆可撤销**：误操作提供撤销路径（提交答题除外，因为考试场景需严肃）。
4. **减层少跳转**：核心链路点击不超过 3 次到达。
5. **无感续会**：token 失效自动续期，不打断训练。
6. **错误友好**：错误页提供重试入口与文案，避免空白。

## 2. 全局交互

### 2.1 启动与登录态
```
冷启动
  → splash 800ms
  → 检查 token
     ├ 有效 → 静默续签 → 首页
     ├ 过期 → wx.login 静默换 token → 首页
     └ 失败 → 登录引导页（仅首次）
```
- **静默续签**：不打断当前页，失败时仅 toast"请重新登录"。
- **登录引导页**：仅"微信一键登录"按钮，无其他干扰。

### 2.2 加载态
| 场景 | 表现 |
|------|------|
| 首次进入页 | 骨架屏（skeleton），占位灰块 |
| 局部刷新 | 顶部下拉 + 旋转 loader |
| 按钮提交 | 按钮 loading + 禁用，防重复 |
| 列表分页 | 底部三点 loader |

### 2.3 空状态
| 场景 | 文案 | 操作 |
|------|------|------|
| 错题本空 | "还没有错题，去刷点题吧" | [去训练] |
| 复习队列空 | "今日复习已完成 🎉" | [看报告] |
| 搜索无结果 | "未找到相关题目" | [清空筛选] |
| 小测无场次 | "本周小测周日 20:00 开考" | — |

### 2.4 错误态
| 错误类型 | 表现 |
|----------|------|
| 网络异常 | 全屏缺省页："网络走丢了" + [重试] |
| 接口 500 | toast "服务开小差，请稍后" + 自动上报 |
| 401 未登录 | 静默续签，失败跳登录引导 |
| 402 需订阅 | 弹订阅引导层（非强制跳转） |
| 429 限流 | toast "操作太快了，歇一下" |

### 2.5 弱网与断网
- 答题请求队列化：断网时本地暂存 userAnswer，恢复后自动补提交。
- 断网超过 30s：答题页顶部黄条"网络异常，答案将在恢复后提交"。
- 历史错题与知识点卡片：离线缓存最近 50 条。

## 3. 学生端核心交互

### 3.1 自由训练答题状态机
```
                ┌──────────┐
        start──►│  作答中  │
                └────┬─────┘
                     │ 选选项
                     ▼
                ┌──────────┐
                 │ 已选定   │ ← 可改选
                 └────┬─────┘
                      │ 点提交
                      ▼
                 ┌──────────┐
                 │  提交中  │ button loading
                 └────┬─────┘
                      │ 接口返回
                      ▼
              ┌──────────────┐
              │ 反馈页(对/错) │
              └──────┬───────┘
                     │
            ┌────────┴────────┐
            ▼                 ▼
       [下一题]          [查看知识点]
            │                 │
            ▼                 ▼
       下一题作答       知识点卡片 → 返回
```
**边界**：
- 提交后不可改答（防止试错刷数据）。
- 同一 (sessionId, questionId) 重复提交 → 后端幂等，返回原结果，不重复计掌握度。
- 提交中退出小程序：下次进入恢复到"反馈页"（基于已落库结果）。

### 3.2 错因归因交互
- 答错后**强制弹层**选错因，不选不能进下一题（避免数据缺失）。
- 错因三选项卡片式，点选高亮，二次点击确认。
- 选"知识点不会" → 反馈页底部出现"📖 查看知识点卡片"按钮。
- 第二次答错同类题 → 反馈页底部追加"⚠ 变式题验证 1/2"，点击进入变式题。

### 3.3 掌握度动效
- 反馈页掌握度条变化：旧档 → 滑动 → 新档，持续 600ms。
- 升档：绿色脉冲 + 向上箭头。
- 降档：红色闪烁 + 向下箭头。
- 旁标"连续答对 N 次"实时数字滚动。

### 3.4 倒计时与限时小测
- 小测倒计时：
  - 正常：右上角灰色数字。
  - 剩余 < 5min：变红 + 轻微闪烁。
  - 剩余 < 1min：每秒滴答音效（可设置关闭）。
  - 到时：自动提交，toast "时间到，已自动交卷"。
- 答题进度：顶部进度条 `3/20`，答完题号变绿。

### 3.5 分页与下拉刷新
- 题库列表、错题本、报告：下拉刷新 + 上拉加载更多。
- 刷新动画：顶部下拉出现旋转 logo，松手回弹。

### 3.6 支付交互
```
订阅页 → [立即订阅]
  → 下单接口
  → 拉起 wx.requestPayment
  → 支付成功
     → toast "订阅成功"
     → 1s 后跳我的页，订阅状态实时刷新
  → 支付取消
     → toast "支付已取消"，停留订阅页
  → 支付失败
     → 弹窗 "支付失败，请重试" + [重试] [联系客服]
```
- **回调延迟**：支付成功页停留 1s 等回调，确保权益已开通；若 5s 未确认，手动触发 `/subscription/status` 刷新。

### 3.7 家长绑定交互（手机号绑定）
```
家长入口 → 输入孩子手机号
  → 校验手机号格式
  → [获取验证码] 按钮 60s 倒计时
  → 输入 6 位验证码
  → [绑定]
     ├ 成功 → toast "绑定成功" → 跳家长报告页
     ├ 验证码错误 → toast "验证码错误"，剩余次数提示
     └ 3 次错误 → 锁定 30min，提示"请稍后再试"
```

## 4. 家长端交互

### 4.1 角色切换
- 同一微信号首次进入默认学生身份。
- 点击"我是家长"切换身份，localStorage 记忆选择。
- 顶部显示当前身份胶囊：[学生] / [家长:小明]。

### 4.2 多孩子切换
- 家长报告页顶部 Tab 切换孩子（如绑定 2 个孩子）。
- 切换无加载动画（数据预取）。

### 4.3 报告更新频率
- 家长报告数据每日 0 点更新，页脚显示"数据更新于 09-17 00:00"。
- 不支持实时刷新，避免家长焦虑。

## 5. 后台交互

### 5.1 列表通用交互
- 筛选：顶部筛选栏，变更后自动查询（debounce 300ms）。
- 排序：表头点击切换升降序。
- 分页：底部 Pagination + 跳页输入。
- 批量：复选框 + 顶部批量操作栏。

### 5.2 表单交互
- 必填项前端校验，失焦即校验。
- 提交前二次校验，错误项滚动定位。
- 草稿：长表单（如新增题目）支持自动保存草稿，30s 无操作触发。

### 5.3 危险操作
- 下架题目、删除、改价、退款：二次确认弹窗 + 输入"确认"二字才能提交（仅改价/退款）。
- 操作后 toast "操作成功"，列表 500ms 后刷新。

### 5.4 题库批量导入交互
```
拖拽上传 JSON
  → 上传进度条
  → 解析校验中（骨架屏）
  → 结果展示：
     ✅ 新增 280
     ⚠ 跳过 15（可下载明细）
     ❌ 拒绝 5（可下载明细）
  → [完成]
```
- 导入失败（如格式错误）：全屏错误页 + [重新上传]。

### 5.5 图表交互
- ECharts 图表 hover 显示 tooltip。
- 长按图表支持下载 PNG（仅后台，便于汇报）。

## 6. 动效规范

### 6.1 通用动效
| 动效 | 时长 | 缓动 |
|------|------|------|
| 页面切换 | 300ms | ease-in-out |
| 弹层出现 | 250ms | ease-out |
| toast | 200ms in / 2000ms 停留 / 200ms out | — |
| 按钮 hover（后台） | 150ms | ease |
| 卡片点击态 | 100ms scale(0.98) | ease |

### 6.2 微交互
- 答对：✅ 图标弹入（scale 0→1.2→1，400ms）。
- 答错：❌ 图标左右抖动（300ms）。
- 掌握度升档：进度条 600ms 平滑过渡。
- 收藏：⭐ 图标旋转一周 + 填充（500ms）。
- 倒计时最后 1 分钟：数字每秒 scale 脉冲。

### 6.3 性能约束
- 动效优先 transform/opacity，避免重排。
- 低端机检测：`wx.getSystemInfo` benchmark < 阈值则关闭非必要动效。
- 尊重用户：系统"减弱动效"设置时自动降级。

## 7. 通知与提醒

### 7.1 订阅消息（微信）
| 场景 | 模板 | 触发 |
|------|------|------|
| 今日复习 | 复习提醒 | 每日 19:00（如未完成） |
| 小测开考 | 小测提醒 | 开考前 10min |
| 订阅到期 | 到期提醒 | 到期前 3 天 |
| 家长绑定成功 | 绑定通知 | 绑定完成时 |
| 周报生成 | 报告提醒 | 每周一 08:00 |

- 首次触发前引导用户授权订阅消息。
- 用户可在小程序内"通知设置"开关单项。

### 7.2 后台站内通知
- 仅运营/异常类：订单异常、对账失败、Job 失败。
- 顶部 🔔 红点，点击进入通知列表。

## 8. 边界与异常处理

### 8.1 训练中断恢复
- 退出小程序再进入：首页提示"你有未完成的训练，[继续]"。
- 训练会话 24h 未完成：自动标记"中断"，不计入统计。

### 8.2 小测异常
- 小测中退出：计时继续，重新进入恢复答题进度（基于本地缓存）。
- 小测结束未提交：自动提交已答部分。
- 小测网络异常：本地缓存答案，恢复后批量提交（仍在截止时间内）。

### 8.3 支付边界
- 同一 planId 5 秒内重复下单：返回原订单。
- 支付成功但权益未到账：进入"我的 → 订阅"自动触发 `/subscription/status` 刷新，最多 3 次重试。
- 微信支付单已支付但本地订单未更新：每日对账 Job 补偿。

### 8.4 题库下架
- 已在学生错题本中的下架题：保留可见，但不可重做，标注"该题已下架"。
- 进行中训练含下架题：跳过该题，不影响会话。

### 8.5 多端一致性
- 同一学生在小程序端与家长端（如自己绑定自己）：数据一致，但家长视角仅汇总。

---

## 9. 可访问性（A11y）
- 文字与背景对比度 ≥ 4.5:1。
- 按钮最小点击区 44×44pt。
- 关键图标提供文字标签（aria-label，后台）。
- 支持系统大字号适配。
- 颜色不仅传达状态（红/绿同时配文字"未掌握/已掌握"）。

## 11. 落地建议
1. 本说明与 11-UI原型图 配套使用，交付 UI 设计师与前端开发。
2. 高保真稿应在 Figma 中补全交互态（hover/active/disabled/loading/empty/error）。
3. 前端开发按本文档实现状态机与边界处理，不可省略异常分支。
4. 动效需在低端机测试，确认性能达标。
