## 1. 测试目标与策略

### 1.1 目标
- 功能正确：覆盖 PRD 全部功能点，回归零 Critical。
- 性能达标：普通接口 P95 < 300ms，批改 < 1s，支持 1k 并发答题。
- 合规：题库无版权风险，史实无错误，敏感表述合规。
- 体验：小程序冷启动 < 3s，分包加载流畅。

### 1.2 测试金字塔
```
        ▲  E2E（5%）       小程序端到端 / 后台端到端
       ▲▲  集成（25%）     API 集成、Service+Mapper、组件交互
     ▲▲▲▲  单元（70%）     Service / 工具函数 / Redux store
```

### 1.3 测试环境
| 环境 | 数据 | 用途 |
|------|------|------|
| dev | 模拟数据 + 少量题 | 开发自测 |
| test | 300+ 题脱敏数据 | 功能/集成测试 |
| staging | 全量题库副本 + 真实支付沙箱 | 预发验收、支付链路 |
| prod | 生产 | 灰度上线 |

## 3. 功能用例矩阵（核心）

### 3.1 学生端

#### 3.1.1 登录
| 用例 ID | 用例 | 预期 |
|---------|------|------|
| ST-LOGIN-01 | 首次微信登录 | 创建 student，返回 token，isNew=true |
| ST-LOGIN-02 | 重复登录 | 复用 student，isNew=false |
| ST-LOGIN-03 | token 过期 | 接口返回 40100，前端静默刷新 |

#### 3.1.2 训练
| 用例 ID | 用例 | 预期 |
|---------|------|------|
| ST-TRAIN-01 | 自由训练按考点组卷 10 题 | 返回 10 题，sessionId 生成 |
| ST-TRAIN-02 | 提交正确答案 | isCorrect=true，掌握度连续答对+1 |
| ST-TRAIN-03 | 提交错误答案 | isCorrect=false，写入 wrong_record，弹错因层 |
| ST-TRAIN-04 | 选错因后第二次答错 | 推送变式题 1~2 道 |
| ST-TRAIN-05 | 同 (sessionId,questionId) 重复提交 | 幂等返回原结果 |
| ST-TRAIN-06 | 错题训练模式 | 仅返回未解决错题 |
| ST-TRAIN-07 | 非订阅用户超免费额度 | 返回 40200，前端跳订阅页 |

#### 3.1.3 掌握度与复习
| 用例 ID | 用例 | 预期 |
|---------|------|------|
| ST-MAS-01 | 连续答对 2 次 | level 升档，nextReviewAt +7 天 |
| ST-MAS-02 | 答错 | 连续归零，level=0，+1 天 |
| ST-MAS-03 | 每日 Job 生成复习队列 | due_date=today 的题进入队列 |
| ST-MAS-04 | 复习过期未做 | status=已过期，level 降档 |

#### 3.1.4 限时小测
| 用例 ID | 用例 | 预期 |
|---------|------|------|
| ST-QUIZ-01 | 未到开考时间 | 拒绝进入 |
| ST-QUIZ-02 | 开考后加入 | 下发 20 题，记录 started_at |
| ST-QUIZ-03 | 到时间未提交 | 自动提交已答部分 |
| ST-QUIZ-04 | 提交批改 | 生成 quiz_result，更新掌握度 |
| ST-QUIZ-05 | 重复提交 | 幂等 |

#### 3.1.5 订阅与支付
| 用例 ID | 用例 | 预期 |
|---------|------|------|
| ST-PAY-01 | 下单 | 返回 paySign，可拉起支付 |
| ST-PAY-02 | 支付回调验签通过 | 写订阅权益 30 天 |
| ST-PAY-03 | 支付回调验签失败 | 拒绝 |
| ST-PAY-04 | 重复回调 | 幂等不重复开通 |
| ST-PAY-05 | 订阅期内再次下单 | 续费叠加，end_at 顺延 |

### 3.2 后台
| 用例 ID | 用例 | 预期 |
|---------|------|------|
| AD-AUTH-01 | 账号密码错误 | 返回 40000 |
| AD-AUTH-02 | 无权限访问题库管理 | 返回 40300，前端 403 页 |
| AD-Q-01 | 新增选择题 | 入库 question + options + knowledge |
| AD-Q-02 | Excel/JSON 批量导入 | 返回 inserted/skipped/conflicted |

| AD-QUIZ-01 | 小测排期配置 | 定时触发正确 |

### 3.3 抓取与题库
| 用例 ID | 用例 | 预期 |
|---------|------|------|
| SC-01 | license 缺失 | 校验失败，不入库 |

## 7. Bug 流程
| 状态 | 流转 |
|------|------|
| 新建 | 测试发现 → 指派开发 |
| 处理中 | 开发认领 |
| 已修复 | 开发自测通过 → 测试验证 |
| 已验证 | 测试通过 → 关闭 |
| 重新打开 | 验证失败 → 回到处理中 |
| 已拒绝 | 非问题/设计如此 |

### 7.1 严重级别
| 级别 | 定义 | SLA |
|------|------|-----|
| P0 Critical | 核心链路不可用/支付错误/数据错乱 | 2h 内修复 |
| P1 Major | 主要功能异常 | 24h |
| P2 Minor | 次要功能/体验 | 1 周 |
| P3 Trivial | 文案/样式 | 随版本 |
