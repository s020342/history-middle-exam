## 1. 设计规范

### 1.1 主题色
- 主色：#3B82F6（蓝）— 训练/CTA
- 辅助：#10B981（绿）— 已掌握/正确
- 警示：#F59E0B（黄）— 部分掌握
- 危险：#EF4444（红）— 未掌握/错误
- 背景：#F9FAFB
- 文字主：#1F2937，次：#6B7280

### 1.2 间距与圆角
- 间距：4/8/12/16/24 倍数。
- 卡片圆角：12px；按钮：8px。
- 字号：标题 18/16、正文 14、辅助 12。

### 1.3 通用组件
- 顶部 Tab Bar：首页 / 训练 / 错题 / 我的（4 个）。
- 卡片：白底 + 阴影 0 1 2 rgba(0,0,0,0.05)。
