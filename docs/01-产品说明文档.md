## 1. 产品概述

### 1.1 产品定位
面向初中生中考历史备考场景的智能训练小程序，以「题池 + 错因归因 + 间隔复习」为核心，帮助学生在有限时间内高效提分。

### 1.2 核心价值
- **题量充足**：历史科目 ≥ 300 道题，覆盖全部主考点，高频考点强化。
- **错误归因**：不只告诉你"做错了"，还告诉你"为什么错"（知识点不会 / 概念混淆 / 审题陷阱）。
- **间隔复习**：基于三档掌握度智能调度，避免"学了就忘"。
- **变式验证**：同类题/变式题二次验证，确保真正掌握。

### 1.3 用户角色
| 角色 | 使用端 | 主要职责 |
|------|--------|----------|
| 学生 | 微信小程序 | 刷题、复习、参加限时小测、查看报告 |
| 家长（次要） | 微信小程序 | 代付订阅、查看孩子学习报告 |
| 管理员/教师 | Web 后台 | 题库管理、学习看板、运营配置 |

## 2. 功能模块

### 2.1 学生端（微信原生小程序）

#### 2.1.1 题型与题池
- **题型**：选择题（单选）、判断题。
- **题池来源**：历年中考真题改编 + 模拟题 + 教师原创混合。
- **数量**：历史科目 ≥ 300 道。
- **考点覆盖**：覆盖全部历史主考点；高频考点题量加权。
- **题目属性**：题干、选项、正确答案、解析、所属考点、难度、来源、来源年份、版权追溯字段。

#### 2.1.2 训练模式
- **自由训练**：按考点 / 题型 / 随机 组卷，即时反馈。
- **限时小测**：每周一次，固定题量与时长，自动批改并生成报告。
- **错题训练**：仅练习历史错题与薄弱知识点。
- **间隔复习**：基于掌握度调度的复习队列，到期自动提醒。

#### 2.1.3 知识点卡片
- 每个主考点配一张知识点卡片：核心结论、时间轴、易错提示、关联题。
- 训练后可查看相关卡片；卡片可收藏。

#### 2.1.4 三档掌握度
每道题/每个知识点按掌握度分三档：
| 档位 | 含义 | 调度策略 |
|------|------|----------|
| 未掌握（红） | 错过或从未答对 | 1 天内复习 |
| 部分掌握（黄） | 答对但有反复 | 3 天内复习 |
| 已掌握（绿） | 连续 2 次答对 | 7 天内复测，过期降档 |

#### 2.1.5 错误归因
每次答错后，系统引导选择/标记错因（可由教师后台预设）：
1. **知识点不会**：关联知识点卡片，推荐学习。
2. **概念混淆**：推送易混对比卡片。
3. **审题陷阱**：标记陷阱类型（如时间错位、主体偷换、绝对化表述）。

#### 2.1.6 同类/变式题验证
答错某题后，推送 1~2 道同类/变式题，连续答对方确认掌握，避免"碰巧答对"。

#### 2.1.7 每周限时小测
- 固定每周一次（如周日 20:00），可补做。
- 题量 20 题 / 时长 20 分钟（可配）。
- 生成排名（可选）、个人报告。

#### 2.1.8 训练报告
- 周报：本周训练量、正确率、掌握度变化、薄弱考点 Top3。
- 错题归因分布饼图。
- 复习完成率。

#### 2.1.9 订阅与支付
| 档位 | 权益 | 说明 |
|------|------|------|
| 免费体验 | 每日 N 题、1 个考点 | 引流转化 |
| 月订阅 | 全题库、间隔复习、限时小测、报告 | 微信支付 |

- 支付方式：微信支付。
- 订阅有效期 30 天，到期前 3 天提醒续费。

### 2.2 管理后台（React + Spring Boot）

#### 2.2.1 学习看板
- 学生列表（活跃度、训练量、正确率、掌握度分布）。
- 单学生详情：错题归因分布、复习完成率、订阅状态。
- 全局统计：日活、题库使用热度、高频错题 Top N。

#### 2.2.2 题库管理
- 题目增删改查：题干、选项、答案、解析、考点、难度、来源。
- 批量导入（JSON）。
- 错因标签管理、变式题关联配置。
- 上下架、审核状态。

#### 2.2.3 运营配置
- 限时小测排期与题量配置。
- 订阅价格、免费额度配置。
- 公告/活动配置。

## 3. 非功能性需求
| 维度 | 要求 |
|------|------|
| 性能 | 题目加载 < 500ms；批改响应 < 1s |
| 可用性 | 小程序 7x24；后台 9x5 |
| 兼容性 | 微信基础库 ≥ 2.10；主流浏览器（后台） |
| 安全 | 学生数据脱敏；支付走微信官方；后台 RBAC |
| 数据量 | 单科 300+ 题、预计首期学生 1k+ |
