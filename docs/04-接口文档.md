## 1. 通用约定

### 1.1 请求
- `Content-Type: application/json; charset=utf-8`
- 鉴权头：`Authorization: Bearer <token>`
- ID 字段以字符串传输，避免 JS 精度丢失。

### 1.2 统一响应
```json
{ "code": 0, "message": "ok", "data": {} }
```
分页响应：
```json
{ "code": 0, "data": { "list": [], "total": 100, "page": 1, "size": 20 } }
```

### 1.3 错误码
| code | 含义 |
|------|------|
| 0 | 成功 |
| 40000 | 参数错误 |
| 40100 | 未登录 |
| 40300 | 无权限 |
| 40400 | 资源不存在 |
| 40900 | 状态冲突（重复提交/重复支付） |
| 42900 | 限流 |
| 40200 | 需订阅 |
| 50000 | 服务器错误 |

### 1.4 分页参数
`?page=1&size=20`，page 从 1 起，size ≤ 100。

## 2. 学生端接口

### 2.1 登录

#### POST `/api/student/auth/login`
微信登录，换取 token。
```
请求：{ "code": "wx login code", "nickname": "...", "avatarUrl": "..." }
响应：{ "token": "...", "studentId": "1001", "isNew": true, "subscribed": false, "subscribedUntil": null }
```

#### GET `/api/student/auth/profile`
获取当前学生信息。
```
响应：{ "studentId":"1001","nickname":"小明","avatarUrl":"...","subscribed":false,"subscribedUntil":null }
```

---

### 2.2 训练

#### POST `/api/student/train/start`
开始训练会话。
```
请求：{ "mode": "FREE|WRONG|REVIEW", "knowledgeIds":["K1"], "count": 10 }
响应：{ "sessionId":"s1","questions":[ {id, type, stem, options:[{key,content}]} ] }
```

#### POST `/api/student/train/answer`
提交单题答案（流式批改）。
```
请求：{ "sessionId":"s1","questionId":"Q1","userAnswer":"A","durationMs":5200 }
响应：{ "correct":true,"answer":"A","analysis":"...","needVariant":false,
        "variantQuestions":[], "mastery":{ "level":2,"nextReviewAt":"2026-09-24" } }
```

#### POST `/api/student/train/wrong-cause`
```
请求：{ "sessionId":"s1","questionId":"Q1","errorCauseCode":"CONCEPT_CONFUSED" }
响应：{ "ok":true }
```

#### POST `/api/student/train/finish`
结束会话。
```
请求：{ "sessionId":"s1" }
响应：{ "total":10,"correct":7,"wrongBookAdded":3 }
```

---

### 2.3 错题本

#### GET `/api/student/wrong-book`
```
请求：?knowledgeId=K1&page=1&size=20
响应：{ list:[{questionId,stem,wrongCount,lastWrongAt,errorCause}], total, page, size }
```

#### DELETE `/api/student/wrong-book/{questionId}`
移除已掌握错题。

---

### 2.4 间隔复习

#### GET `/api/student/review/today`
```
响应：{ "dueCount":5,"questions":[{questionId,stem,...}] }
```

#### POST `/api/student/review/answer`
复用 `/train/answer` 入参（mode=REVIEW 自动识别）。

---

### 2.5 知识点卡片

```
响应：{ "tree":[{id,name,children:[{id,name}],isHighFreq:true}] }
```

```
响应：{ "id":"K1","name":"...","cardContent":"# markdown","cardImage":"url",
        "questions":[{questionId,stem}] }
```

### 2.6 限时小测

#### GET `/api/student/quiz/list`
```
响应：{ "list":[{scheduleId,title,startAt,endAt,status,joined}] }
```

#### POST `/api/student/quiz/join`
```
请求：{ "scheduleId":"q1" }
响应：{ "sessionId":"qs1","questionCount":20,"durationMin":20,
        "endAt":"2026-09-21T20:20:00","questions":[{...}] }
```

#### POST `/api/student/quiz/submit`
```
请求：{ "sessionId":"qs1","answers":[{questionId,userAnswer}] }
响应：{ "score":85,"correct":17,"total":20,"resultId":"r1" }
```

#### GET `/api/student/quiz/result/{resultId}`
```
响应：{ score, correct, total, durationMs, details:[{questionId,userAnswer,isCorrect,answer,analysis}] }
```

## 3. 后台接口

### 3.1 登录与权限

#### POST `/api/admin/auth/login`
```
请求：{ "username":"admin","password":"..." }
响应：{ "token":"...","admin":{id,name,roles:["ADMIN"]} }
```

#### GET `/api/admin/auth/menu`
返回当前用户菜单与权限码。

---

### 3.2 学习看板

#### GET `/api/admin/dashboard/overview`
```
请求：?from=&to=
响应：{ "dau":320,"newStudents":12,"trainCount":5200,"avgCorrectRate":76.2 }
```

#### GET `/api/admin/dashboard/students`
```
请求：?keyword=&orderBy=active&page=1&size=20
响应：{ list:[{studentId,nickname,trainCount,correctRate,masteryDist:{0:10,1:30,2:60},subscribed,lastActiveAt}], total }
```

#### GET `/api/admin/dashboard/students/{id}`
```
响应：{ profile, errorCauseDist, masteryTrend:[{date,level0,level1,level2}], reviewDoneRate, subscription }
```

#### GET `/api/admin/dashboard/hot-wrong`
```
响应：{ list:[{questionId,stem,wrongCount,wrongRate}] }
```

---

### 3.3 题库管理

#### GET `/api/admin/question/list`
```
请求：?type=&knowledgeId=&sourceType=&status=&keyword=&page=&size=
响应：{ list:[{id,type,stem,difficulty,sourceType,status,correctRate}], total }
```

#### POST `/api/admin/question`
新增。body：{ type, stem, options, answer, analysis, knowledgeIds:[{id,isPrimary}], difficulty, sourceType, sourceYear, sourceDesc, variantQuestionIds, license, author, sourceUrl }

#### PUT `/api/admin/question/{id}`
更新，字段同上。

#### DELETE `/api/admin/question/{id}`
软删（status=下架）。

#### POST `/api/admin/question/import`
> 题库批量导入（对接数据抓取方案文档产出的 JSON 文件）。multipart 上传 .json，返回导入统计。

#### POST `/api/admin/question/{id}/variant`
关联变式题：{ variantQuestionId, relationType }

## 4. 公共说明

### 4.1 限流
- 登录：60/min/IP
- 答题：300/min/学生
- 后台导入：1/min/管理员

### 4.2 幂等
- `POST /train/answer` 以 `(sessionId, questionId)` 幂等。
- `POST /subscription/order` 同一 planId 5 秒内幂等。
- `POST /quiz/submit` 以 sessionId 幂等。

### 4.3 文件上传
- 题目图片：`POST /api/admin/upload/image` → 返回 OSS url。
- 题库导入：`POST /api/admin/question/import` 见 3.3。
